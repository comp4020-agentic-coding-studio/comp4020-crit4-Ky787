# Crit 4 — An Instrument

## 1. What was the breakthrough that moved the work forward?

My initial thought was to use a privated curated dataset of ~10 hours of syncronised piano concerto MIDI-Audio recordings into a site that would be interactable. However in order to satisfy the crit requirements I instead asked a claude session to do perpare MIDI's for presentation on the site from the dataset, while another claude session perpared the website itself. This meant I could set the CLAUDE.md to include a harness telling the agent to work from the real synced MIDI's rather than just make one up. 

## 2. What did this work change about who I want to be as a software developer?

Having more experience in using separate claude agents to perform different tasks for the website was an efficent approach as the main prompt the build the site was vetted and prepared by myself and a previous claude session instead of one shotting it from a normal prompt. In the future I will plan my projects with AI to have this design.
